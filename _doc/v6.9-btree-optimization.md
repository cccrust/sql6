# v6.9 - BTree 效能優化

## 日期
2026-05-15

## 主要功能

### 1. Page Cache（頁面快取）
- LRU 快取熱門頁面
- 預設 64MB
- 與 DirStorage 整合

### 2. Bloom Filter
- 快速判斷 key 是否存在
- 1MB, 7 hashes
- 與 DirStorage 整合

### 3. 模組重構
將 storage.rs 拆分為獨立模組：

| 檔案 | 說明 |
|------|------|
| `storage.rs` | Storage trait + MemoryStorage + LruCacheStorage |
| `file_btree_storage.rs` | 單一檔案 BTree 儲存 |
| `dir_btree_storage.rs` | 目錄式 BTree 儲存（含 PageCache + BloomFilter） |
| `dir_lsmtree_storage.rs` | LSM Tree 儲存引擎 |
| `cache.rs` | 頁面快取與 Bloom Filter |
