# v6.1 規劃 - 模組化與平行化

## 目標
將 sql6 升級為高度模組化、可抽換後端、支援多執行緒並發的資料庫系統。

## 架構變更

### 1. 資料儲存方式
- **現有**：單一資料庫檔案 (db.sql6)
- **目標**：單一資料夾多檔案 (db.sql6/)
  ```
  mydb.sql6/
  ├── data/          # 資料頁面
  ├── index/          # 索引檔案
  ├── wal/            # WAL 日誌
  ├── meta/           # 中繼資料
  └── schema/         # 結構定義
  ```

### 2. 儲存引擎抽換 (Storage Backend Abstraction)
支援可抽換的儲存後端：
- **BTree**：現有 B+Tree 實現，適合讀取密集
- **LSM Tree**：Log-Structured Merge，適合寫入密集
- **Memory**：記憶體引擎 (現有)

```rust
trait StorageEngine {
    fn read(&self, page_id: PageId) -> Result<Page>;
    fn write(&mut self, page_id: PageId, data: &Page) -> Result<()>;
    fn flush(&mut self) -> Result<()>;
    // ...
}

enum Storage {
    BTree(BTreeStorage),
    LsmTree(LsmStorage),
    Memory(MemoryStorage),
}
```

### 3. 高度平行 (High Parallelism)
- **多執行緒讀取**：Reader threads 可並發讀取
- **寫入鎖細分化**：Row-level vs page-level locks
- **事務隔離**：MVCC 實現
- **連線池**：Connection pooling

### 4. 傳輸模式（保持）
- Memory 模式 (in-memory database)
- Disk 模式 (file-based)
- WebSocket 模式 (多客戶端)
- stdio/Pipe 模式 (程序間通訊)
- HTTP API 模式 (REST)

### 5. 全文檢索（保持）
- 原生 CJK FTS5（bigram 分詞，無需額外斷詞）
- 向量相似度搜尋 (cosine, euclidean)
