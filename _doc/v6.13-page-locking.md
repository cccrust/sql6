# v6.13 - 頁面級鎖定

## 日期
2026-05-15

## 主要功能

### 1. Per-Page Locking（頁面級鎖定）
- 使用 PageLockManager 實現
- `lock_shared()` - 共享鎖（讀）
- `lock_exclusive()` - 排他鎖（寫）

### 2. 並發讀取優化
- 多執行緒可同時讀取不同頁面
- 讀取共用同一頁面時自動串列
