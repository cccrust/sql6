# v6.2 規劃 - 多檔案儲存 + Page Lock

## 目標
將 sql6 從單一檔案模式升級為單一資料夾多檔案模式，並實現頁面級鎖定以支援高並發。

## 主要變更

### 1. 儲存結構 (單一資料夾多檔案)

```
mydb.sql6/                    # 資料庫目錄
├── catalog.meta              # 中繼資料（表格結構、索引等）
├── data/                     # 資料頁面目錄
│   └── pages_0.dat           # 資料頁面檔
├── index/                    # 索引目錄
│   └── btree_0.idx           # BTree 索引檔
├── wal/                      # WAL 日誌目錄
│   └── wal_0.log             # WAL 檔
└── lock/                     # 鎖定狀態目錄
    └── page_locks.json       # 頁面鎖定狀態
```

### 2. 頁面級鎖定 (Page-Level Locking)

取代全局資料庫鎖，改用頁面鎖：

```rust
enum LockMode {
    Shared,     // 共享鎖（多讀）
    Exclusive, // 排他鎖（單寫）
}

struct PageLock {
    page_id: u32,
    mode: LockMode,
    holder: ThreadId,
    timestamp: u64,
}
```

## API 變更

### 開啟資料庫
```python
# 舊版（單一檔案）
conn = sql6.connect("mydb.sql6")

# 新版（資料夾）
conn = sql6.connect("mydb.sql6/")  # 或自動偵測
```

### 頁面鎖 API（內部）
```rust
// 讀取頁面（共享鎖）
let page = storage.lock_read(page_id)?;

// 寫入頁面（排他鎖）
storage.lock_write(page_id, &page)?;
```
