# v6.0 - 從 sql5 升級至 sql6

## 更新日期
2026-05-15

## 概述
從 sql5 分支升級為 sql6，準備發展為更強大、快速、模組化、高度平行的資料庫系統。

## 變更內容

### 名稱變更
- 專案名稱：sql5 → sql6
- Crate 名稱：sql5 → sql6 (Cargo.toml)
- Python 套件：sql5 → sql6 (PyPI)
- WAL 檔案：.sql5wal → .sql6wal
- 資料庫檔案：.sql5db → .sql6db
- 環境變數：SQL5_BINARY → SQL6_BINARY

### 目錄變更
- `sql5_pypi/` → `sql6_pypi/`
- `sql5web.sh` → `sql6web.sh`

### 測試檔案變更
- `test_sql5.py` → `test_sql6.py`
- `sql5test.py` → `sql6test.py`

## 保留功能
- 原生 CJK FTS5 全文檢索（無需斷詞）
- Memory/Disk 模式
- WebSocket/Pipe/API 傳輸模式
- 向量相似度搜尋 (v4.0)
- 所有 SQL 相容性
