# v6.4 規劃 - 效能優化與生產環境準備

## 目標
提升效能、增加連線池支援、最佳化查詢執行，為生產環境做準備。

## 主要功能

### 1. 連接池 (Connection Pool)

```rust
// 連接池配置
struct PoolConfig {
    max_connections: usize,    // 最大連線數
    min_idle: usize,          // 最小空閒連線
    connection_timeout: Duration,
    idle_timeout: Duration,
}

// 使用範例
let pool = Sql6Pool::new("mydb.sql6", PoolConfig {
    max_connections: 10,
    min_idle: 2,
    ..Default::default()
});

let conn = pool.get()?;  // 自動取得連線
// 使用完自動歸還連線
```

### 2. 查詢快取 (Query Cache)

```rust
// 快取已編譯的查詢計劃
struct QueryCache {
    cache: RwLock<HashMap<String, Arc<QueryPlan>>>,
    max_size: usize,
}

// 相同 SQL 只編譯一次
let plan = cache.get_or_insert(sql, || parse_and_plan(sql));
```

### 3. Bloom Filter 優化（延續 v6.3）

```rust
struct BloomFilter {
    bits: Vec<u64>,
    num_hashes: usize,
}

// LSM Tree 查詢時快速過濾不存在
if !bloom.might_contain(key) {
    return None;  // 快速跳過

```

### 4. 索引加速

- 支援多索引同時使用
- 索引覆蓋查詢（只讀索引不回讀資料頁）
- 複合索引

### 5. 平行查詢

```rust
// 並行掃描多個資料分片
fn parallel_scan(&self, range: KeyRange) -> impl Iterator<Item=Row> {
    self.shards.iter()
        .map(|shard| shard.scan(range))
        .collect::<FuturesUnordered<_>>()
}
```

### 6. 統計資訊

```sql
-- 分析表格統計
ANALYZE table_name;

-- 查看統計
PRAGMA table_info('table_name');
PRAGMA index_list('table_name');
PRAGMA query_plan('SELECT * FROM t WHERE id = ?');
```
